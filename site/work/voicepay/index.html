VoicePay

A multilingual, voice-first UPI payment SDK for mobile apps and IVR systems, built for Amazon HackOn Season 5.

TypeScript, Node.js, Firebase, GitHub Actions.

The ring shows a simulated voice. Press Speak to let it follow yours. The microphone is only used on this page, and nothing is recorded or sent anywhere.

Problem

Payment apps assume that you can see a screen and work through its menus. For visually impaired and non-technical users that assumption is a wall.

Approach

Make the voice the interface. VoicePay is a software development kit, so the same voice flow can sit inside a mobile app or behind an IVR, the menu system you reach by phone call, and it speaks more than one language.
